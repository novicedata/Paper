### Overview

This repository contains the code and supplementary materials for our manuscript:

> **"MZ세대 공무원의 이직의도 해석"**  
> 저자: [신연우], [김진영], [이태헌]  

> 초록: 본 연구는 MZ세대 공무원의 이직의도를 예측하고 그 결정요인을 심층적으로 분석하기 위해 설명가능 인공지능(Explainable AI, XAI) 기법인 RuleFit을 활용하였다. 분석 결과, 공직만족, 보상 인식, 조직몰입, 직무 역량, 가족 책임 등의 요인이 특정 조건에서 결합할 때 이직의도가 높아지는 것으로 나타났다. 예컨대 공직만족도가 낮고 자녀 부양 책임이 없는 경우 이직의도가 증가한 반면, 공직에 대한 자부심과 보상에 대한 만족이 높은 경우에는 이직의도가 낮게 나타났다. 아울러 전체 응답자의 절반 이상은 적극적으로 이직을 계획하지 않으면서도 조직에 대한 헌신 수준이 낮은 ‘소극적 잔류자’ 집단으로 확인되었다. RuleFit은 이러한 복합적 조건에 따른 상황별 패턴을 규칙 형태로 도출함으로써, 공공 인사정책 수립을 위한 실증적 근거와 해석 가능성을 제공한다.
